# Проверка выпуска

Проверка выполнена 9 ноября 2026 года. Ниже отделены результаты исполнения от документированной совместимости.

## Сборка и установщик

Команды из корня репозитория:

```sh
uv run --no-project python scripts/build.py
uv run --no-project python -m unittest discover -s tests -v
uv run --no-project python scripts/build.py --check
```

Сборка содержит **7 навыков для 6 харнессов: 42 самостоятельных каталога**. Десять тестов пройдены:

1. Состав исходных навыков, основные метаданные и наличие ресурсов.
2. Полнота 42 вариантов и контрольные суммы каждого файла.
3. Отсутствие записей при предварительном просмотре установки.
4. Копирование всех семи навыков для каждого из шести харнессов в изолированные тестовые каталоги, сохранение лицензий и источников.
5. Отказ от перезаписи существующего пользовательского навыка.
6. Отказ от неизвестного имени и попытки выхода через `../`.
7. Отказ от каталога назначения с символической ссылкой.
8. Отказ от повторного имени навыка в одном запросе.
9. Отказ от установки изменённой сборки с несовпадающими контрольными суммами.
10. Установка отдельно выбранного навыка.

Это проверки сборки и копирования файлов. Они не означают, что во всех шести приложениях был запущен агент и выполнен полный исследовательский сценарий.

## Исполняемые учебные примеры

Два поставляемых синтетических скрипта отдельно прочитаны и повторно выполнены при итоговой проверке в изолированном окружении uv. Все внутренние утверждения-проверки прошли. Запуск с `python -I` через `uv run --no-project --python <интерпретатор-окружения>` исключал влияние стороннего PYTHONPATH.

| Пример | Проверенный результат |
|---|---|
| Сравнение Уэлча | Разность A − B = 0,4526259901; t = 1,820974342; df = 67,22537957; p = 0,07306109; интервал разности [−0,04347632; 0,94872830] |
| Парный анализ | 29 полных пар, одна исключённая пара; статистика сверена с одновыборочным тестом разностей |
| Регрессия HC3 | Конечные коэффициенты и интервалы; исходные условия — независимые ошибки, не кластерная панель |
| Планирование | 64 наблюдения на группу в заданном t-дизайне; 159 всего в заданной трёхгрупповой ANOVA |
| Сеть | 5 узлов, 4 ребра, 1 изолят; компоненты размером 4 и 1 |
| Взвешенный путь | A → B → C, стоимость 2; сила связи и расстояние не смешивались |
| GraphML | Запись и повторное чтение сохранили тип, узлы, изолят, рёбра и проверяемые атрибуты |

Эти числа относятся **только к искусственным данным**, созданным скриптами, и не являются исследованием социальных групп. Примеры также отклоняют некорректные входы: NaN, бесконечности, недопустимые расстояния и вырожденные выборки в проверяемых функциях.

Фактические версии итогового повторного запуска: Python 3.13.14, NumPy 2.5.4, SciPy 1.18.1, statsmodels 0.15.0, NetworkX 3.7. Это журнал выполнения, не обещание совместимости с любым выпуском. Зависимости не встроены в установщик.

## Методические и редакторские проверки

Проверены явные ограничения причинных выводов, различение рефлексивного тематического анализа и оценки согласия кодировщиков, запрет выдуманного пилотажа, знаменатели опросов, защита исходников и конфиденциальность. Источники и сведения о лицензиях сохранены. Русский текст проверен редакторски и локальным линтером; терминологические перечисления не удалялись ради нулевого числа предупреждений.

## Не проверено

- Полный запуск публичных адаптаций во всех шести харнессах с моделью. Подтверждены документированные способы обнаружения и вызова, см. [harnesses.md](harnesses.md).
- Реальная когнитивная апробация примеров анкеты и гайда на участниках.
- Байесовское семплирование, множественная импутация, расчёты сложной опросной выборки, survival-модели и статистическое сравнение сетей с нулевым ансамблем.
- Работа всех возможных сторонних библиотек, браузерных и Office-интеграций.

Автоматическая проверка в GitHub Actions дополнительно выполняет сборку, тесты установщика и контроль воспроизводимости `dist/`. Её фактический статус смотрите во вкладке Actions соответствующего коммита; этот документ не заменяет статус CI.
