# Адаптация для Pi coding agent

Используй стандартный каталог Agent Skills Pi; прочитай SKILL.md и связанные файлы через доступный инструмент чтения. Файловые операции и вычисления выполняй штатными инструментами текущей сессии Pi, не командами Hermes. Возможности поиска, браузера, работы с Office и делегирования зависят от подключённых расширений: проверь их наличие, не придумывай встроенные инструменты. Если подходящего инструмента нет, сообщи ограничение и выбери проверяемую локальную альтернативу. Не устанавливай расширения и не передавай данные участников внешним сервисам только ради завершения примера. Идентификаторы участников и секреты не помещай в конфигурацию или публичный репозиторий.

## Общие ограничения исполнения

Используй Python только через uv и явно выбранное изолированное окружение проекта. Не изменяй Python харнесса или системы. Вычисления выполняй инструментами; не выдавай иллюстративные числа за результаты. Не отправляй персональные данные наружу без разрешения. Формат и язык ответа определяются текущей задачей; по умолчанию используй русский язык. Не загружай другие навыки только потому, что они упомянуты в тексте: сначала проверь их доступность.
