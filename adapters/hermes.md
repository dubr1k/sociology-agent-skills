# Адаптация для Hermes Agent

Загружай этот SKILL.md через `skill_view`; связанные материалы — тем же инструментом с `file_path`. Используй `read_file`, `search_files`, `terminal` и доступный веб-поиск по задаче. Не считай наличие навыка доказательством наличия пакетов, сервисов или ключей. В многопрофильной установке работай только в выбранном профиле; не подменяй его каталогом default. Делегируй независимые части только доступным механизмом Hermes, сохраняя реестр охвата. Полученные от помощников выводы сверяй с исходниками. Публичная версия не требует личного operating-contract или иных непоставляемых навыков. При наличии локальных правил соблюдай их, но не публикуй их вместе с результатами.

## Общие ограничения исполнения

Используй Python только через uv и явно выбранное изолированное окружение проекта. Не изменяй Python харнесса или системы. Вычисления выполняй инструментами; не выдавай иллюстративные числа за результаты. Не отправляй персональные данные наружу без разрешения. Формат и язык ответа определяются текущей задачей; по умолчанию используй русский язык. Не загружай другие навыки только потому, что они упомянуты в тексте: сначала проверь их доступность.
