# Адаптация для Claude Code

Используй каталог как Claude Code skill: основной файл SKILL.md и относительные references/templates. Для файлов применяй доступные Read, Write/Edit; Glob/Grep — только если они действительно включены, для вычислений — Bash с разрешениями текущего проекта. Не вызывай Hermes `skill_view` и не используй каталоги веб-приложения Claude вместо проекта Claude Code. Текущий запрос, CLAUDE.md и настройки разрешений учитываются без отключения подтверждений. Не используй режимы обхода разрешений ради чтения закрытого корпуса. Делегирование необязательно; итоговый агент проверяет источники и результаты. Не создавай DOCX только потому, что пример upstream предполагал Word: формат определяет задача.

## Общие ограничения исполнения

Используй Python только через uv и явно выбранное изолированное окружение проекта. Не изменяй Python харнесса или системы. Вычисления выполняй инструментами; не выдавай иллюстративные числа за результаты. Не отправляй персональные данные наружу без разрешения. Формат и язык ответа определяются текущей задачей; по умолчанию используй русский язык. Не загружай другие навыки только потому, что они упомянуты в тексте: сначала проверь их доступность.
