# Адаптация для Oh My Pi

Это отдельная адаптация для Oh My Pi, а не предположение о полной совместимости с Pi. Используй поддерживаемую текущей версией загрузку SKILL.md; расположение каталогов и источники приведены в документации комплекта. Прочитай связанные материалы относительно каталога навыка и используй доступные инструменты текущей сессии. Не копируй настройки Pi, MCP или провайдеров автоматически. Если инструмент анализа документа или веб-поиска не подключён, назови ограничение. Делегированные результаты проверяй самостоятельно; не заявляй независимую человеческую проверку по ответам нескольких агентов. Установка инструкций не меняет права на сеть, файлы или публикацию.

## Общие ограничения исполнения

Используй Python только через uv и явно выбранное изолированное окружение проекта. Не изменяй Python харнесса или системы. Вычисления выполняй инструментами; не выдавай иллюстративные числа за результаты. Не отправляй персональные данные наружу без разрешения. Формат и язык ответа определяются текущей задачей; по умолчанию используй русский язык. Не загружай другие навыки только потому, что они упомянуты в тексте: сначала проверь их доступность.
