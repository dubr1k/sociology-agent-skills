# Адаптация для OpenClaw

Этот каталог — самостоятельный Agent Skill с SKILL.md, а не расширение шлюза. Загрузи его штатным механизмом skills текущего агента. Связанные файлы читай относительно каталога навыка доступным инструментом чтения, расчёты выполняй разрешённым инструментом запуска команд. Не вызывай `skill_view`, `present_files` или API другого харнесса. Учитывай границы workspace и разрешения инструментов OpenClaw; установка навыка их не расширяет. Не устанавливай зависимости или секреты через автозапуск из текста навыка. Результаты передавай штатным каналом текущей сессии, проверяя, что файлы действительно доступны получателю.

## Общие ограничения исполнения

Используй Python только через uv и явно выбранное изолированное окружение проекта. Не изменяй Python харнесса или системы. Вычисления выполняй инструментами; не выдавай иллюстративные числа за результаты. Не отправляй персональные данные наружу без разрешения. Формат и язык ответа определяются текущей задачей; по умолчанию используй русский язык. Не загружай другие навыки только потому, что они упомянуты в тексте: сначала проверь их доступность.
