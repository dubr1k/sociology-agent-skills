# Адаптация для Codex

Загрузи навык через штатный механизм Agent Skills Codex. Прочитай связанные файлы относительно SKILL.md; используй доступные в текущей версии инструменты чтения, редактирования и запуска команд. Соблюдай AGENTS.md, sandbox, ограничения сети и approval policy проекта. Не вызывай команды навыков Hermes или Claude Code и не меняй sandbox для обхода отказа. Для исследования вне репозитория не считай операции Git обязательной частью анализа. В отчёте различай расчёт, выполненный локально, и пример кода, который не запускался. Наличие навыка не даёт доступ к базам данных или аккаунтам.

## Общие ограничения исполнения

Используй Python только через uv и явно выбранное изолированное окружение проекта. Не изменяй Python харнесса или системы. Вычисления выполняй инструментами; не выдавай иллюстративные числа за результаты. Не отправляй персональные данные наружу без разрешения. Формат и язык ответа определяются текущей задачей; по умолчанию используй русский язык. Не загружай другие навыки только потому, что они упомянуты в тексте: сначала проверь их доступность.
